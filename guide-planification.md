# Guide Planification Réseaux Sociaux

## Option 1 : Meta Business Suite (gratuit)

1. Va sur https://business.facebook.com/
2. Connecte-toi avec ton compte Facebook
3. Crée une **Page** si pas déjà fait
4. Clique sur **Meta Business Suite** → **Planificateur**
5. Ajoute ton compte Instagram
6. Crée un post :
   - Choisis la date/heure
   - Colle le texte
   - Ajoute l'image
   - Publie sur Facebook + Instagram simultanément
7. Clique **Planifier**

## Option 2 : Buffer (gratuit, 3 posts)

1. Va sur https://buffer.com/
2. Connecte-toi avec Facebook
3. Ajoute jusqu'à 3 posts dans la file d'attente
4. Ils seront publiés automatiquement

- Très efficace

BROME ✅
- Pas d'odeur
- Efficace à pH élevé
